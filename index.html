⚙ Prototype Scope & Limitations This web deployment is a lightweight prototype intended for sample-wise demonstration and research validation. The framework was trained and evaluated on the full 3,256-image dataset offline. The deployed app supports single-image and small-batch inference via API. Large-scale batch processing (3,200+ images) requires dedicated server-side GPU infrastructure and is outside the scope of this academic prototype.
